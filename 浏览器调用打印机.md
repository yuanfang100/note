### 问题和需求

> 浏览器中用代码开启打印机存在的问题就是布局和样式问题，这里使用 第三方插件 print-js 来解决

#### 1、安装和引入

```sh
pnpm i print-js

import print from "print-js";
```

#### 2、使用

> 需要创建一个 dom 盒子，然后打印区域就是这个盒子，将需要打印的内容丢进这个盒子；

```html
<div id="printBox">
 <div>我是打印内容</div>
</div>
```



#### 3、调用打印

> 代码中写的 css 能控制打印出来的样式布局；其中的 class 等都是 区域内的内容

```js
print({
      printable: "printBox", // 标签元素id
      type: "html",
      // header: "打印一下",
      documentTitle: "打印一下333", // 标题
      // ---这两行不能少---------
      scanStyles: false,
      targetStyles: ["*"],
      // ------------
      // body {zoom: 50%;}
      style: `@page {size:auto;margin-top:60px;margin-bottom:60px; margin-left:50px; margin-right: 50px;}
      .personData {
        margin: 0 auto;
        padding: 35px 50px;
        box-sizing: border-box;
        text-align: center;
        width: 330px;
        height: 440px;
        background-image: url("/images/qr-bg.png");
        background-size: 100% 100%;
        background-repeat: no-repeat;
        color: #fff;
        border:1px solid #000;
      }
      .personData img {
        width: 160px;
        max-height: 200px;
      }
      .personData .name {
        font-size: 25px;
        margin: 15px 0 5px;
      }
      .personData p {
        font-size: 18px;
        margin-bottom: 15px;
      }
      .personData .qr {
        display: flex;
        align-items: center;
        justify-content: center;
      }
      .personData .qr.dian {
        margin: 0 auto;
      }
      `,
    });
```
