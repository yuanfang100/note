# 15. 函数

函数是组织代码的重要工具。它可以把一段完成特定任务的代码封装起来，避免重复，让程序结构更清晰。

本章目标：

1. 理解函数的作用。
2. 掌握定义函数和调用函数。
3. 掌握参数、返回值、默认参数。
4. 理解变量作用域。
5. 能用函数重构小项目。

---

## 1. 为什么需要函数

如果一段代码要使用很多次，就应该考虑写成函数。

### 示例 1：重复代码

```python
print("==========")
print("学生成绩")
print("==========")

print("==========")
print("班级排名")
print("==========")
```

讲解：分隔线重复出现，代码不够整洁。

### 示例 2：使用函数

```python
def print_title(title):
    print("==========")
    print(title)
    print("==========")

print_title("学生成绩")
print_title("班级排名")
```

讲解：函数让重复逻辑只写一次。

### 示例 3：函数表达一个任务

```python
def is_passed(score):
    return score >= 60

print(is_passed(72))
```

讲解：函数名应该清楚表达它完成什么任务。

## 2. 定义和调用函数

函数用 `def` 定义。

### 示例 1：无参数函数

```python
def say_hello():
    print("你好，Python")

say_hello()
```

讲解：定义函数不会自动执行，必须调用。

### 示例 2：函数中多行代码

```python
def show_menu():
    print("1. 添加")
    print("2. 查询")
    print("3. 退出")

show_menu()
```

讲解：函数体中的代码需要缩进。

### 示例 3：多次调用

```python
def line():
    print("-" * 20)

line()
print("内容")
line()
```

讲解：函数可以重复调用。

---

## 3. 参数

参数是传给函数的数据。

### 示例 1：一个参数

```python
def greet(name):
    print("你好，" + name)

greet("李华")
greet("王宁")
```

讲解：不同参数会产生不同结果。

### 示例 2：多个参数

```python
def add(a, b):
    print(a + b)

add(3, 5)
add(10, 20)
```

讲解：调用时传入的值要和参数对应。

### 示例 3：关键字参数

```python
def show_student(name, score):
    print(name, score)

show_student(score=88, name="李华")
```

讲解：关键字参数可以不按位置顺序，但要写清楚参数名。

---

## 4. 返回值 return

`return` 用于把函数计算结果返回给调用者。

### 示例 1：返回加法结果

```python
def add(a, b):
    return a + b

result = add(3, 5)
print(result)
```

讲解：有返回值的函数可以继续参与计算。

### 示例 2：返回判断结果

```python
def is_even(number):
    return number % 2 == 0

print(is_even(10))
print(is_even(11))
```

讲解：函数可以返回布尔值。

### 示例 3：return 后函数结束

```python
def check_score(score):
    if score < 0 or score > 100:
        return "无效分数"
    if score >= 60:
        return "及格"
    return "不及格"

print(check_score(80))
```

讲解：执行到 `return` 后，函数会立即结束。

## 5. 默认参数

默认参数是在调用时没有传值时使用的参数值。

### 示例 1：默认问候对象

```python
def greet(name="同学"):
    print("你好，" + name)

greet()
greet("李华")
```

讲解：不传参数时使用默认值。

### 示例 2：默认重复次数

```python
def repeat(text, times=3):
    print(text * times)

repeat("Hi")
repeat("Hi", 5)
```

讲解：默认参数让函数调用更灵活。

### 示例 3：默认及格线

```python
def is_passed(score, pass_score=60):
    return score >= pass_score

print(is_passed(70))
print(is_passed(70, 80))
```

讲解：默认值可以表达常见规则，也允许调用者修改规则。

## 6. 作用域

变量的作用域表示变量能在哪里使用。

### 示例 1：局部变量

```python
def test():
    number = 10
    print(number)

test()
```

讲解：`number` 在函数内部创建，属于局部变量。

### 示例 2：全局变量

```python
message = "hello"

def show():
    print(message)

show()
```

讲解：函数可以读取外部变量，但不建议过度依赖。

### 示例 3：用返回值传递结果

```python
def create_score():
    score = 90
    return score

result = create_score()
print(result)
```

讲解：如果需要函数内部结果，推荐用 `return` 返回。

## 7. 函数处理列表和字典

### 示例 1：计算平均分

```python
def average(scores):
    return sum(scores) / len(scores)

print(average([88, 95, 76]))
```

讲解：函数可以接收列表作为参数。

### 示例 2：找最高分学生

```python
def find_best(students):
    best = students[0]
    for student in students:
        if student["score"] > best["score"]:
            best = student
    return best

students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95}
]
print(find_best(students))
```

讲解：函数可以处理复杂数据结构。

### 示例 3：筛选优秀学生

```python
def filter_excellent(students):
    result = []
    for student in students:
        if student["score"] >= 90:
            result.append(student)
    return result

students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95}
]
print(filter_excellent(students))
```

讲解：函数返回筛选后的新列表。

## 8. 函数拆分项目

一个完整程序可以拆成多个函数。

### 示例 1：显示菜单

```python
def show_menu():
    print("1. 添加成绩")
    print("2. 查看成绩")
    print("3. 退出")

show_menu()
```

讲解：显示菜单是独立任务，适合函数。

### 示例 2：计算总分

```python
def total_score(scores):
    total = 0
    for score in scores:
        total = total + score
    return total

print(total_score([80, 90, 100]))
```

讲解：把计算逻辑放进函数，主程序更清楚。

### 示例 3：成绩分析

```python
def analyze(scores):
    return {
        "average": sum(scores) / len(scores),
        "max": max(scores),
        "min": min(scores)
    }

result = analyze([88, 95, 76])
print(result)
```

讲解：函数可以返回字典，让多个结果带有清楚名称。

## 9. 模块化思想

模块化就是把代码按功能拆分。Python 文件本身也可以作为模块。

### 示例 1：导入 random

```python
import random

print(random.randint(1, 10))
```

讲解：模块提供了别人写好的功能。

### 示例 2：只导入一个函数

```python
from math import sqrt

print(sqrt(16))
```

讲解：`sqrt()` 用于开平方。

### 示例 3：给模块起别名

```python
import random as rd

print(rd.randint(1, 6))
```

讲解：别名可以让模块名更短，但不要滥用。

## 10. 易错点

### 示例 1：忘记调用函数

```python
def hello():
    print("hello")

hello()
```

讲解：只有定义没有调用，函数不会执行。

### 示例 2：参数数量不匹配

```python
def add(a, b):
    return a + b

print(add(1, 2))
```

讲解：调用时参数数量要符合定义。

### 示例 3：print 和 return 不同

```python
def add_print(a, b):
    print(a + b)

def add_return(a, b):
    return a + b

result = add_return(3, 5)
print(result * 2)
```

讲解：`print` 只是显示，`return` 才能把结果交给后续代码使用。
