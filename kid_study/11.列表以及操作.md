# 11. 列表以及操作

列表是 Python 中最常用的数据结构之一。它适合保存一组有顺序、可以修改的数据，比如成绩列表、商品列表、任务列表、学生名单。

本章目标：

1. 理解列表的特点。
2. 掌握创建、读取、修改、添加、删除。
3. 掌握遍历、切片、排序、统计。
4. 理解列表嵌套和列表推导式。
5. 能用列表解决常见数据处理问题。

---

## 1. 列表的基本概念

列表使用方括号 `[]` 表示，元素之间用逗号分隔。列表是有顺序的，并且可以修改。

### 示例 1：数字列表

```python
scores = [88, 95, 76, 91]
print(scores)
```

讲解：列表可以保存多个数字，顺序和写入顺序一致。

### 示例 2：字符串列表

```python
subjects = ["语文", "数学", "英语"]
print(subjects)
```

讲解：列表可以保存多个字符串。

### 示例 3：混合类型列表

```python
student = ["李华", 13, 88.5, True]
print(student)
```

讲解：Python 允许列表中放不同类型的数据，但实际项目中通常建议保持结构清晰。

---

## 2. 读取列表元素

列表通过索引读取元素。索引从 0 开始。

### 示例 1：读取第一个元素

```python
scores = [88, 95, 76]
print(scores[0])
```

讲解：索引 0 表示第一个元素。

### 示例 2：读取最后一个元素

```python
scores = [88, 95, 76]
print(scores[-1])
```

讲解：索引 `-1` 表示最后一个元素。

### 示例 3：读取列表长度

```python
scores = [88, 95, 76]
print(len(scores))
```

讲解：`len()` 返回列表中元素的个数。

---

## 3. 修改列表元素

列表是可变的，可以通过索引修改元素。

### 示例 1：修改一个成绩

```python
scores = [88, 95, 76]
scores[2] = 80
print(scores)
```

讲解：把索引 2 的成绩从 76 改成 80。

### 示例 2：批量修改

```python
numbers = [1, 2, 3]
for i in range(len(numbers)):
    numbers[i] = numbers[i] * 10
print(numbers)
```

讲解：通过索引循环，可以修改列表中的每个元素。

### 示例 3：注意索引越界

```python
scores = [88, 95, 76]
# scores[3] = 100
print(scores)
```

讲解：列表只有索引 0、1、2，访问索引 3 会报错。

---

## 4. 添加元素

常见添加方法有 `append()`、`insert()`、`extend()`。

### 示例 1：append 添加到末尾

```python
subjects = ["语文", "数学"]
subjects.append("英语")
print(subjects)
```

讲解：`append()` 每次添加一个元素到末尾。

### 示例 2：insert 插入到指定位置

```python
subjects = ["语文", "英语"]
subjects.insert(1, "数学")
print(subjects)
```

讲解：`insert(1, "数学")` 表示插入到索引 1 的位置。

### 示例 3：extend 合并列表

```python
list1 = [1, 2]
list2 = [3, 4]
list1.extend(list2)
print(list1)
```

讲解：`extend()` 会把另一个列表的元素逐个添加进来。

---

## 5. 删除元素

常见删除方式有 `remove()`、`pop()`、`del`、`clear()`。

### 示例 1：remove 按值删除

```python
fruits = ["苹果", "香蕉", "橙子"]
fruits.remove("香蕉")
print(fruits)
```

讲解：`remove()` 删除第一个匹配的值。

### 示例 2：pop 按位置删除

```python
fruits = ["苹果", "香蕉", "橙子"]
removed = fruits.pop(1)
print(removed)
print(fruits)
```

讲解：`pop()` 会删除并返回指定位置的元素。

### 示例 3：clear 清空列表

```python
fruits = ["苹果", "香蕉", "橙子"]
fruits.clear()
print(fruits)
```

讲解：`clear()` 会清空整个列表。

---

## 6. 遍历列表

遍历就是逐个处理列表元素。

### 示例 1：直接遍历元素

```python
scores = [88, 95, 76]
for score in scores:
    print(score)
```

讲解：这种写法适合只读取元素。

### 示例 2：使用索引遍历

```python
scores = [88, 95, 76]
for i in range(len(scores)):
    print(i, scores[i])
```

讲解：如果需要位置编号，可以使用索引。

### 示例 3：enumerate 同时得到索引和值

```python
subjects = ["语文", "数学", "英语"]
for index, subject in enumerate(subjects):
    print(index, subject)
```

讲解：`enumerate()` 比手动索引更简洁。

---

## 7. 列表切片

切片可以得到列表的一部分。

### 示例 1：取前三个

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[:3])
```

讲解：结果包含索引 0、1、2。

### 示例 2：取中间部分

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[1:4])
```

讲解：包含索引 1 到 3，不包含索引 4。

### 示例 3：反转列表

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[::-1])
```

讲解：切片步长为 `-1` 可以反向取值。

## 8. 排序和统计

### 示例 1：排序

```python
scores = [88, 95, 76, 91]
scores.sort()
print(scores)
```

讲解：`sort()` 会修改原列表。

### 示例 2：降序排序

```python
scores = [88, 95, 76, 91]
scores.sort(reverse=True)
print(scores)
```

讲解：`reverse=True` 表示从大到小排序。

### 示例 3：统计

```python
scores = [88, 95, 76, 91]
print(sum(scores))
print(max(scores))
print(min(scores))
print(sum(scores) / len(scores))
```

讲解：列表常和 `sum()`、`max()`、`min()`、`len()` 配合使用。

## 9. 列表嵌套

列表中可以继续放列表。

### 示例 1：二维列表

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
]
print(matrix[0])
print(matrix[1][2])
```

讲解：`matrix[1][2]` 表示第 2 行第 3 个元素。

### 示例 2：多个学生成绩

```python
scores = [
    ["李华", 88],
    ["王宁", 95],
    ["赵敏", 76]
]
for item in scores:
    print(item[0], item[1])
```

讲解：嵌套列表能表示简单表格，但字段含义不如字典清楚。

### 示例 3：统计二维列表总和

```python
matrix = [
    [1, 2, 3],
    [4, 5, 6]
]
total = 0
for row in matrix:
    for number in row:
        total = total + number
print(total)
```

讲解：嵌套列表通常需要嵌套循环处理。

## 10. 列表推导式

列表推导式可以用更简洁的方式创建列表。

### 示例 1：生成平方数

```python
squares = [number * number for number in range(1, 6)]
print(squares)
```

讲解：生成 1 到 5 的平方。

### 示例 2：筛选偶数

```python
numbers = [1, 2, 3, 4, 5, 6]
evens = [number for number in numbers if number % 2 == 0]
print(evens)
```

讲解：列表推导式可以带条件。

### 示例 3：成绩加分

```python
scores = [55, 60, 73]
new_scores = [score + 5 for score in scores]
print(new_scores)
```

讲解：适合对列表每个元素做相同处理。

## 11. 易错点

### 示例 1：append 和 extend 区别

```python
a = [1, 2]
a.append([3, 4])
print(a)

b = [1, 2]
b.extend([3, 4])
print(b)
```

讲解：`append()` 把整个列表当成一个元素，`extend()` 把元素逐个加入。

### 示例 2：排序会修改原列表

```python
scores = [88, 95, 76]
sorted_scores = sorted(scores)
print(scores)
print(sorted_scores)
```

讲解：`sorted()` 返回新列表，不修改原列表。

### 示例 3：遍历时删除要小心

```python
scores = [55, 60, 45, 80]
passed = []
for score in scores:
    if score >= 60:
        passed.append(score)
print(passed)
```

讲解：不要一边遍历原列表一边随意删除，推荐创建新列表保存结果。
