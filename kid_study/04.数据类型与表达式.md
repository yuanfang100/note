# 04. 数据类型与表达式

数据类型决定了数据能做什么操作。数字可以计算，字符串可以拼接，布尔值可以做判断。理解类型，是写出正确程序的基础。

本章目标：

1. 认识整数、浮点数、字符串、布尔值。
2. 理解表达式和运算符。
3. 掌握常见数学运算。
4. 理解比较表达式和逻辑表达式。
5. 为后续类型转换、列表、字典打基础。

---

## 1. 整数 int

整数是不带小数点的数字，可以是正数、负数或 0。

### 示例 1：年龄和数量

```python
age = 13
book_count = 6
print(age)
print(book_count)
```

讲解：年龄、人数、数量通常适合用整数。

### 示例 2：整数运算

```python
a = 18
b = 5
print(a + b)
print(a - b)
print(a * b)
```

讲解：整数可以进行基本四则运算。

### 示例 3：负整数

```python
temperature = -4
print("当前温度：", temperature)
```

讲解：温度、海拔变化、账户欠款等可能用负数表示。

---

## 2. 浮点数 float

浮点数是带小数点的数字。

### 示例 1：身高

```python
height = 1.68
print(height)
```

讲解：身高、体重、价格、平均值常用浮点数。

### 示例 2：除法结果

```python
average = 95 / 2
print(average)
```

讲解：普通除法 `/` 的结果通常是浮点数。

### 示例 3：浮点数计算

```python
price = 3.5
count = 4
total = price * count
print(total)
```

讲解：浮点数可以和整数一起计算。

---

## 3. 字符串 str

字符串用于表示文本，必须写在引号中。

### 示例 1：姓名

```python
name = "张晨"
print(name)
```

讲解：文字数据使用字符串保存。

### 示例 2：字符串拼接

```python
first_name = "张"
last_name = "晨"
full_name = first_name + last_name
print(full_name)
```

讲解：字符串可以用 `+` 拼接。

### 示例 3：字符串重复

```python
line = "-" * 20
print(line)
```

讲解：字符串乘整数表示重复，常用于输出分隔线。

---

## 4. 布尔值 bool

布尔值只有两个：`True` 和 `False`，表示真和假。

### 示例 1：直接保存真假

```python
is_student = True
is_holiday = False
print(is_student)
print(is_holiday)
```

讲解：布尔值常用于记录状态。

### 示例 2：比较得到布尔值

```python
score = 85
print(score >= 60)
print(score >= 90)
```

讲解：比较表达式的结果是布尔值。

### 示例 3：布尔值用于条件

```python
is_raining = True
if is_raining:
    print("带伞")
```

讲解：`if` 后面需要一个能判断真假的条件。

## 5. 数学运算符

常见数学运算符：

- `+` 加
- `-` 减
- `*` 乘
- `/` 除
- `//` 整除
- `%` 取余
- `**` 次方

### 示例 1：整除

```python
print(17 // 5)
```

讲解：17 除以 5 商 3，所以整除结果是 3。

### 示例 2：取余

```python
print(17 % 5)
```

讲解：17 除以 5 余 2，所以结果是 2。

### 示例 3：次方

```python
print(2 ** 3)
print(10 ** 2)
```

讲解：`2 ** 3` 表示 2 的 3 次方。

## 6. 表达式和优先级

表达式是由数据、变量、运算符组成的计算式。Python 会根据优先级计算。

### 示例 1：乘法优先

```python
result = 2 + 3 * 4
print(result)
```

讲解：先算乘法，所以结果是 14。

### 示例 2：括号改变顺序

```python
result = (2 + 3) * 4
print(result)
```

讲解：括号内先算，所以结果是 20。

### 示例 3：复杂表达式

```python
a = 10
b = 4
c = 2
result = (a + b) * c - a / c
print(result)
```

讲解：复杂表达式要适当使用括号，提高可读性。

## 7. 比较和逻辑表达式

比较运算符用于比较两个值：

- `>` 大于
- `<` 小于
- `>=` 大于等于
- `<=` 小于等于
- `==` 等于
- `!=` 不等于

逻辑运算符用于连接多个条件：

- `and` 并且
- `or` 或者
- `not` 取反

### 示例 1：比较表达式

```python
score = 78
print(score >= 60)
print(score == 100)
print(score != 0)
```

讲解：每个比较表达式都会得到 `True` 或 `False`。

### 示例 2：and

```python
score = 85
attendance = 95
print(score >= 80 and attendance >= 90)
```

讲解：`and` 要求两个条件都为真。

### 示例 3：or 和 not

```python
has_ticket = False
is_vip = True
print(has_ticket or is_vip)
print(not has_ticket)
```

讲解：`or` 满足一个即可，`not` 会把真假反过来。
