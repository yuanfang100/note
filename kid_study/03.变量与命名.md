# 03. 变量、赋值与命名规范

变量是程序保存数据的基本方式。初中阶段学习变量，不仅要知道“变量能装数据”，还要理解赋值、命名、可读性和变量变化过程。

本章目标：

1. 理解变量和赋值语句。
2. 掌握变量命名规则和命名风格。
3. 理解变量值可以改变。
4. 学会用变量表达数学公式和现实数据。
5. 区分“能运行”和“写得好”。

---

## 1. 变量是什么

变量是一个名字，它指向程序中的某个数据。

```python
age = 13
```

这行代码不是数学里的“相等”，而是赋值：把右边的 `13` 保存起来，并用左边的名字 `age` 表示它。

### 示例 1：保存年龄

```python
age = 13
print(age)
```

讲解：`age` 是变量名，`13` 是变量值。

### 示例 2：保存姓名

```python
student_name = "李华"
print(student_name)
```

讲解：字符串数据可以用变量保存。

### 示例 3：保存表达式结果

```python
total_score = 88 + 92 + 95
print(total_score)
```

讲解：Python 会先计算右边表达式，再把结果赋给变量。

---

## 2. 赋值语句的执行过程

赋值语句从右往左理解：先计算右边，再把结果交给左边变量名。

### 示例 1：右边先计算

```python
result = 10 * 3 + 5
print(result)
```

讲解：先计算 `10 * 3 + 5` 得到 `35`，再赋值给 `result`。

### 示例 2：变量参与计算

```python
price = 12
count = 4
total = price * count
print(total)
```

讲解：右边可以使用已经存在的变量。

### 示例 3：变量更新

```python
score = 80
score = score + 5
print(score)
```

讲解：第二行先取旧的 `score` 值 80，加 5 后得到 85，再存回 `score`。

## 3. 命名规则

Python 变量名必须遵守规则：

1. 可以包含字母、数字、下划线。
2. 不能以数字开头。
3. 不能包含空格。
4. 不能使用 Python 关键字。
5. 大小写敏感，`score` 和 `Score` 是不同变量。

### 示例 1：正确命名

```python
math_score = 95
student_age = 13
class_number = 7
print(math_score, student_age, class_number)
```

讲解：这些名字清楚、合法，适合实际程序。

### 示例 2：数字不能开头

```python
# 1score = 90
score1 = 90
print(score1)
```

讲解：`1score` 不合法，`score1` 合法。

### 示例 3：不能有空格

```python
# student score = 90
student_score = 90
print(student_score)
```

讲解：多个单词通常用下划线连接。

---

## 4. 命名风格

好的变量名会让程序像文章一样容易阅读。Python 推荐使用小写字母加下划线的风格，称为 snake_case。

### 示例 1：不推荐的名字

```python
a = 88
b = 92
c = (a + b) / 2
print(c)
```

讲解：代码能运行，但不容易看出含义。

### 示例 2：推荐的名字

```python
chinese_score = 88
math_score = 92
average_score = (chinese_score + math_score) / 2
print(average_score)
```

讲解：变量名直接表达数据意义。

### 示例 3：布尔变量命名

```python
is_passed = True
has_homework = False
can_register = True
print(is_passed, has_homework, can_register)
```

讲解：布尔变量常用 `is_`、`has_`、`can_` 开头，表示真假状态。

## 5. 多变量赋值

Python 支持一次给多个变量赋值，但要注意可读性。

### 示例 1：分别赋值

```python
name = "王强"
age = 13
score = 89
print(name, age, score)
```

讲解：初学和正式代码中，这种写法通常最清晰。

### 示例 2：一行赋多个值

```python
x, y = 3, 5
print(x)
print(y)
```

讲解：左边变量数量要和右边值数量一致。

### 示例 3：交换两个变量

```python
a = 10
b = 20
a, b = b, a
print(a)
print(b)
```

讲解：Python 可以很方便地交换变量值，这在排序算法中很常用。

---

## 6. 常量的习惯写法

Python 没有真正强制的常量，但程序员通常用全大写表示“不希望被修改”的值。

### 示例 1：圆周率

```python
PI = 3.14159
radius = 5
area = PI * radius * radius
print(area)
```

讲解：`PI` 用大写表示它应该被当作固定值。

### 示例 2：及格线

```python
PASS_SCORE = 60
score = 72
print(score >= PASS_SCORE)
```

讲解：把规则写成有名字的值，代码更容易维护。

### 示例 3：最大重试次数

```python
MAX_TRY = 3
try_count = 1
print(try_count <= MAX_TRY)
```

讲解：常量常用于表示规则、限制、配置。

## 7. 变量常见问题

### 示例 1：使用不存在的变量

```python
# print(score)
score = 90
print(score)
```

讲解：使用变量前必须先赋值。

### 示例 2：大小写混淆

```python
score = 90
# print(Score)
print(score)
```

讲解：`score` 和 `Score` 是两个不同名字。

### 示例 3：变量类型变化

```python
value = 100
print(value)
value = "一百分"
print(value)
```

讲解：Python 允许同一个变量名先保存数字，再保存字符串。但实际写代码时，不建议随意改变变量含义。
