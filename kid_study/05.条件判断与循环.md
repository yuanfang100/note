# 05. 条件判断与循环

程序的三种基本结构是：顺序、分支、循环。顺序让程序一步步执行，分支让程序根据条件选择路径，循环让程序重复处理任务。

本章目标：

1. 掌握 `if`、`elif`、`else`。
2. 理解条件表达式和代码块缩进。
3. 掌握 `for` 和 `while` 循环。
4. 理解 `break`、`continue`。
5. 能用条件和循环处理简单数据。

---

## 1. if 判断

`if` 用来表示“如果条件成立，就执行某段代码”。

### 示例 1：判断及格

```python
score = 72
if score >= 60:
    print("及格")
```

讲解：条件为真时，缩进的代码会执行。

### 示例 2：判断正数

```python
number = 8
if number > 0:
    print("正数")
```

讲解：比较表达式 `number > 0` 的结果是布尔值。

### 示例 3：判断字符串

```python
password = "abc123"
if password == "abc123":
    print("密码正确")
```

讲解：字符串也可以使用 `==` 比较。

---

## 2. if else

`else` 表示条件不成立时执行另一段代码。

### 示例 1：及格或不及格

```python
score = 55
if score >= 60:
    print("及格")
else:
    print("不及格")
```

讲解：两个分支只会执行其中一个。

### 示例 2：奇偶判断

```python
number = 17
if number % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

讲解：取余 `%` 常用于判断整除和奇偶。

### 示例 3：是否成年

```python
age = 14
if age >= 18:
    print("成年人")
else:
    print("未成年人")
```

讲解：程序可以根据年龄输出不同结果。

---

## 3. if elif else

当情况超过两种时，使用 `elif`。

### 示例 1：成绩等级

```python
score = 86
if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("不及格")
```

讲解：程序从上到下判断，执行第一个成立的分支。

### 示例 2：温度建议

```python
temperature = 32
if temperature >= 35:
    print("高温，注意防暑")
elif temperature >= 25:
    print("天气较热")
elif temperature >= 10:
    print("天气适中")
else:
    print("天气寒冷")
```

讲解：分支适合表达规则判断。

### 示例 3：简单菜单

```python
choice = "2"
if choice == "1":
    print("查看成绩")
elif choice == "2":
    print("录入成绩")
elif choice == "3":
    print("退出系统")
else:
    print("无效选择")
```

讲解：菜单程序常使用多分支判断。

---

## 4. 嵌套判断

一个 `if` 里面还可以写另一个 `if`，这叫嵌套判断。

### 示例 1：先判断及格，再判断优秀

```python
score = 92
if score >= 60:
    print("及格")
    if score >= 90:
        print("优秀")
```

讲解：内层判断只有在外层条件成立后才会执行。

### 示例 2：登录检查

```python
username = "admin"
password = "123456"
if username == "admin":
    if password == "123456":
        print("登录成功")
    else:
        print("密码错误")
else:
    print("用户不存在")
```

讲解：嵌套判断可以表达更细的逻辑，但层数太多会影响可读性。

### 示例 3：范围判断

```python
score = 75
if score >= 0:
    if score <= 100:
        print("分数有效")
```

讲解：这个例子也可以用 `and` 改写。

## 5. for 循环

`for` 循环常用于遍历序列或重复固定次数。

### 示例 1：重复输出

```python
for i in range(5):
    print("Python")
```

讲解：`range(5)` 会产生 0 到 4，循环执行 5 次。

### 示例 2：输出 1 到 10

```python
for number in range(1, 11):
    print(number)
```

讲解：`range(1, 11)` 包含 1，不包含 11。

### 示例 3：遍历列表

```python
scores = [80, 95, 72]
for score in scores:
    print(score)
```

讲解：循环会依次取出列表中的每个元素。

---

## 6. while 循环

`while` 循环在条件为真时一直执行，适合“不确定重复次数”的任务。

### 示例 1：从 1 数到 5

```python
number = 1
while number <= 5:
    print(number)
    number = number + 1
```

讲解：循环变量必须变化，否则可能变成死循环。

### 示例 2：密码尝试

```python
password = ""
while password != "123456":
    password = input("请输入密码：")
print("登录成功")
```

讲解：只要密码不正确，就继续输入。

### 示例 3：累加到指定值

```python
total = 0
number = 1
while total < 100:
    total = total + number
    number = number + 1
print(total)
```

讲解：当停止条件和计算结果有关时，`while` 很合适。

## 7. break 和 continue

`break` 用于提前结束循环，`continue` 用于跳过本轮循环剩余代码。

### 示例 1：找到目标后停止

```python
for number in range(1, 11):
    if number == 6:
        break
    print(number)
```

讲解：遇到 6 时循环结束。

### 示例 2：跳过偶数

```python
for number in range(1, 11):
    if number % 2 == 0:
        continue
    print(number)
```

讲解：偶数会跳过 `print()`，所以只输出奇数。

### 示例 3：查找第一个及格分数

```python
scores = [45, 50, 61, 80]
for score in scores:
    if score >= 60:
        print("第一个及格分数：", score)
        break
```

讲解：找到第一个符合条件的数据后，不必继续遍历。

## 8. 循环综合：统计数据

### 示例 1：统计及格人数

```python
scores = [55, 60, 73, 91, 48]
count = 0
for score in scores:
    if score >= 60:
        count = count + 1
print(count)
```

讲解：计数器是循环统计中的常用技巧。

### 示例 2：求最大值

```python
numbers = [12, 5, 27, 9]
max_number = numbers[0]
for number in numbers:
    if number > max_number:
        max_number = number
print(max_number)
```

讲解：先假设第一个最大，再逐个比较。

### 示例 3：筛选数据

```python
scores = [55, 60, 73, 91, 48]
passed_scores = []
for score in scores:
    if score >= 60:
        passed_scores.append(score)
print(passed_scores)
```

讲解：符合条件的数据可以放入新列表。
