# 12. 字典以及操作

字典是 Python 中非常重要的数据结构，用来保存“键-值”对应关系。它适合表示一个对象的信息，也适合做快速查询。

本章目标：

1. 理解键值对的概念。
2. 掌握字典创建、读取、修改、添加、删除。
3. 掌握遍历字典。
4. 掌握字典嵌套和列表中字典。
5. 能用字典完成数据查询与统计。

---

## 1. 字典基础

字典使用大括号 `{}`，每一项由键和值组成。

### 示例 1：学生信息

```python
student = {"name": "李华", "age": 13, "score": 88}
print(student)
```

讲解：`name` 是键，`李华` 是对应的值。

### 示例 2：商品价格

```python
prices = {"apple": 3.5, "banana": 2.0, "milk": 6.8}
print(prices)
```

讲解：字典适合保存名称和价格的对应关系。

### 示例 3：空字典

```python
contacts = {}
contacts["李华"] = "13800000001"
print(contacts)
```

讲解：可以先创建空字典，再逐步添加数据。

---

## 2. 读取字典

### 示例 1：使用键读取

```python
student = {"name": "李华", "age": 13, "score": 88}
print(student["name"])
```

讲解：通过键可以读取对应值。

### 示例 2：使用 get

```python
student = {"name": "李华", "age": 13}
print(student.get("score"))
print(student.get("score", "暂无成绩"))
```

讲解：`get()` 读取不存在的键时不会报错，可以设置默认值。

### 示例 3：判断键是否存在

```python
student = {"name": "李华", "age": 13}
if "score" in student:
    print(student["score"])
else:
    print("没有成绩")
```

讲解：读取不确定存在的键时，最好先判断。

---

## 3. 添加和修改

给字典的键赋值：如果键不存在就是添加，如果键已存在就是修改。

### 示例 1：添加新键

```python
student = {"name": "李华"}
student["age"] = 13
print(student)
```

讲解：`age` 原来不存在，所以新增。

### 示例 2：修改已有值

```python
student = {"name": "李华", "score": 88}
student["score"] = 95
print(student)
```

讲解：`score` 已存在，所以修改原值。

### 示例 3：update 批量更新

```python
student = {"name": "李华", "score": 88}
student.update({"age": 13, "score": 90})
print(student)
```

讲解：`update()` 可以一次添加或修改多个键值对。

---

## 4. 删除字典项

### 示例 1：del 删除

```python
student = {"name": "李华", "age": 13, "score": 88}
del student["age"]
print(student)
```

讲解：`del` 删除指定键值对。

### 示例 2：pop 删除并返回

```python
student = {"name": "李华", "age": 13, "score": 88}
score = student.pop("score")
print(score)
print(student)
```

讲解：`pop()` 会返回被删除的值。

### 示例 3：clear 清空

```python
student = {"name": "李华", "age": 13}
student.clear()
print(student)
```

讲解：`clear()` 清空整个字典。

---

## 5. 遍历字典

### 示例 1：遍历键

```python
student = {"name": "李华", "age": 13, "score": 88}
for key in student:
    print(key)
```

讲解：直接遍历字典时，得到的是键。

### 示例 2：遍历值

```python
student = {"name": "李华", "age": 13, "score": 88}
for value in student.values():
    print(value)
```

讲解：`values()` 得到所有值。

### 示例 3：遍历键和值

```python
student = {"name": "李华", "age": 13, "score": 88}
for key, value in student.items():
    print(key, value)
```

讲解：`items()` 是最常用的字典遍历方式。

---

## 6. 字典嵌套

字典中可以继续放字典。

### 示例 1：多个科目成绩

```python
student = {
    "name": "李华",
    "scores": {
        "语文": 88,
        "数学": 95,
        "英语": 90
    }
}
print(student["scores"]["数学"])
```

讲解：先通过 `scores` 找到内部字典，再读取数学成绩。

### 示例 2：班级学生

```python
class_data = {
    "李华": {"age": 13, "score": 88},
    "王宁": {"age": 14, "score": 95}
}
print(class_data["王宁"]["score"])
```

讲解：字典嵌套适合按名字快速查找学生。

### 示例 3：遍历嵌套字典

```python
class_data = {
    "李华": {"age": 13, "score": 88},
    "王宁": {"age": 14, "score": 95}
}
for name, info in class_data.items():
    print(name, info["age"], info["score"])
```

讲解：外层遍历姓名和信息，内层读取具体字段。

## 7. 列表中字典

这是实际开发中非常常见的数据结构。

### 示例 1：学生列表

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
print(students)
```

讲解：每个字典表示一个学生，列表保存多个学生。

### 示例 2：筛选优秀学生

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
for student in students:
    if student["score"] >= 90:
        print(student["name"])
```

讲解：列表负责遍历，字典负责保存字段。

### 示例 3：计算平均分

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
total = 0
for student in students:
    total = total + student["score"]
print(total / len(students))
```

讲解：这是一种很常见的数据处理方式。

## 8. 字典统计

字典常用于统计次数。

### 示例 1：统计字符次数

```python
text = "banana"
counts = {}
for char in text:
    counts[char] = counts.get(char, 0) + 1
print(counts)
```

讲解：`get(char, 0)` 表示如果字符不存在，就从 0 开始。

### 示例 2：统计分数段

```python
scores = [55, 60, 73, 91, 98]
result = {"不及格": 0, "及格": 0, "优秀": 0}
for score in scores:
    if score >= 90:
        result["优秀"] = result["优秀"] + 1
    elif score >= 60:
        result["及格"] = result["及格"] + 1
    else:
        result["不及格"] = result["不及格"] + 1
print(result)
```

讲解：字典可以保存多个统计结果。

### 示例 3：商品总价

```python
prices = {"apple": 3, "banana": 2}
cart = {"apple": 4, "banana": 5}
total = 0
for name, count in cart.items():
    total = total + prices[name] * count
print(total)
```

讲解：两个字典可以配合完成查询和计算。

## 9. 易错点

### 示例 1：读取不存在的键

```python
student = {"name": "李华"}
# print(student["score"])
print(student.get("score", 0))
```

讲解：不确定键是否存在时，优先使用 `get()` 或先判断。

### 示例 2：键必须不可变

```python
data = {}
data["name"] = "李华"
data[1] = "数字键"
print(data)
```

讲解：字符串、数字、元组可以作为键，列表不能作为键。

### 示例 3：字典没有索引顺序操作

```python
student = {"name": "李华", "score": 88}
for key, value in student.items():
    print(key, value)
```

讲解：字典主要通过键访问，不像列表那样主要通过索引访问。
