# 16. int()：整数转换函数详解

`int()` 是 Python 中非常常用的内置函数。它的主要作用是把合适的数据转换成整数，也可以用来把不同进制的字符串转换成十进制整数。

在实际编程中，`int()` 经常出现在这些场景：

- 把用户输入的年龄、分数、数量转换成整数。
- 把文件中读出来的数字文本转换成整数。
- 把小数去掉小数部分。
- 把二进制、八进制、十六进制字符串转换成整数。
- 在异常处理中判断用户输入是否合法。

本章目标：

1. 理解 `int()` 的基本作用。
2. 掌握字符串、浮点数、布尔值转整数。
3. 理解 `int()` 不是四舍五入。
4. 掌握 `base` 参数。
5. 学会处理 `ValueError` 和 `TypeError`。

---

## 1. int() 是什么

`int` 是 integer 的缩写，意思是整数。`int()` 可以把某些数据转换成整数。

基本写法：

```python
int(数据)
```

也可以指定进制：

```python
int(字符串, 进制)
```

### 示例 1：字符串转整数

```python
age_text = "13"
age = int(age_text)
print(age)
print(type(age))
```

讲解：`"13"` 原来是字符串，经过 `int()` 后变成整数 `13`。

### 示例 2：输入内容转整数

```python
score = int(input("请输入分数："))
print(score + 5)
```

讲解：`input()` 得到的一定是字符串。如果要计算，需要用 `int()` 转换。

### 示例 3：计算两个输入整数的和

```python
a = int(input("请输入第一个整数："))
b = int(input("请输入第二个整数："))
print(a + b)
```

讲解：如果不使用 `int()`，两个输入会按字符串拼接，而不是数字加法。

---

## 2. 为什么 input() 后经常要用 int()

`input()` 负责接收用户输入，但它不判断你输入的是数字还是文字，它统一返回字符串。

### 示例 1：不转换会发生字符串拼接

```python
a = input("输入第一个数：")
b = input("输入第二个数：")
print(a + b)
```

讲解：如果输入 `10` 和 `20`，结果是 `1020`，因为字符串的 `+` 是拼接。

### 示例 2：转换后才是数字加法

```python
a = int(input("输入第一个数："))
b = int(input("输入第二个数："))
print(a + b)
```

讲解：输入 `10` 和 `20`，转换后结果是整数 `30`。

### 示例 3：年龄计算

```python
age = int(input("请输入年龄："))
print("明年你", age + 1, "岁")
```

讲解：年龄要参与加法，所以应该转成整数。

---

## 3. 字符串转整数

字符串转整数要求字符串内容必须像一个合法整数。

### 示例 1：普通数字字符串

```python
number = int("123")
print(number)
```

讲解：`"123"` 可以转换成整数 `123`。

### 示例 2：带正负号的字符串

```python
print(int("+123"))
print(int("-123"))
```

讲解：字符串前面可以有 `+` 或 `-`。

### 示例 3：带空格的字符串

```python
print(int("  123  "))
```

讲解：字符串两端的空格可以被忽略。

---

## 4. 哪些字符串不能直接转 int

并不是所有字符串都能转整数。

### 示例 1：普通文字不能转换

```python
# number = int("abc")
print("abc 不能直接转换成整数")
```

讲解：`"abc"` 不是数字形式，转换会报 `ValueError`。

### 示例 2：小数字符串不能直接用 int 转

```python
# number = int("3.14")
print("3.14 是小数字符串，不能直接用 int() 转")
```

讲解：`int("3.14")` 会报错。可以先用 `float()` 转成小数，再用 `int()`。

### 示例 3：带单位的字符串不能直接转换

```python
# height = int("170cm")
print("170cm 包含单位，不能直接转换")
```

讲解：`int()` 只能处理纯整数形式的字符串，不能自动理解 `cm`。

---

## 5. 先清理字符串再转换

真实数据经常带空格、单位、符号，需要先处理字符串，再转换。

### 示例 1：去掉两端空格

```python
text = "  88  "
score = int(text.strip())
print(score)
```

讲解：`strip()` 去掉两端空白，再用 `int()` 转换。

### 示例 2：去掉单位

```python
text = "170cm"
height = int(text.replace("cm", ""))
print(height)
```

讲解：先把单位 `cm` 去掉，剩下 `"170"` 才能转换。

### 示例 3：从逗号数据中取出分数

```python
line = "李华,88"
name, score_text = line.split(",")
score = int(score_text)
print(name, score)
```

讲解：文件和表格数据常常需要先拆分，再转换。

---

## 6. 浮点数转整数

`int()` 可以把浮点数转成整数，但它不是四舍五入，而是直接去掉小数部分。

### 示例 1：正小数转整数

```python
print(int(3.14))
print(int(3.99))
```

讲解：结果都是 `3`，不会四舍五入。

### 示例 2：负小数转整数

```python
print(int(-3.14))
print(int(-3.99))
```

讲解：结果都是 `-3`。`int()` 是向 0 的方向截断小数部分。

### 示例 3：先 float 再 int

```python
text = "3.14"
number = int(float(text))
print(number)
```

讲解：`"3.14"` 不能直接 `int()`，但可以先 `float()`，再 `int()`。

---

## 7. int() 和 round() 的区别

`int()` 是截断小数部分，`round()` 是四舍五入附近的取整方式。

### 示例 1：int 不四舍五入

```python
print(int(3.6))
```

讲解：结果是 `3`。

### 示例 2：round 会取近似整数

```python
print(round(3.6))
```

讲解：结果是 `4`。

### 示例 3：成绩平均分处理

```python
average = 89.7
print(int(average))
print(round(average))
```

讲解：如果要保留“整数部分”，用 `int()`；如果要近似到最接近的整数，用 `round()`。

---

## 8. 布尔值转整数

布尔值 `True` 和 `False` 也能转成整数。

### 示例 1：True 转 1

```python
print(int(True))
```

讲解：`True` 转成整数是 `1`。

### 示例 2：False 转 0

```python
print(int(False))
```

讲解：`False` 转成整数是 `0`。

### 示例 3：统计条件成立次数

```python
scores = [55, 60, 90]
count = 0
for score in scores:
    count = count + int(score >= 60)
print(count)
```

讲解：`score >= 60` 得到布尔值，及格为 `True`，转成 1；不及格为 `False`，转成 0。

## 9. int() 的 base 参数

`int()` 可以把不同进制的字符串转换成十进制整数。

格式：

```python
int(字符串, base)
```

`base` 表示字符串原来是什么进制。

### 示例 1：二进制转十进制

```python
number = int("1010", 2)
print(number)
```

讲解：二进制 `1010` 等于十进制 `10`。

### 示例 2：八进制转十进制

```python
number = int("17", 8)
print(number)
```

讲解：八进制 `17` 等于十进制 `15`。

### 示例 3：十六进制转十进制

```python
number = int("FF", 16)
print(number)
```

讲解：十六进制 `FF` 等于十进制 `255`。

---

## 10. base 参数常见进制

常见进制有：

- 2：二进制，只能使用 0 和 1。
- 8：八进制，可以使用 0 到 7。
- 10：十进制，可以使用 0 到 9。
- 16：十六进制，可以使用 0 到 9 和 A 到 F。

### 示例 1：二进制字符串

```python
print(int("1111", 2))
```

讲解：二进制 `1111` 等于十进制 `15`。

### 示例 2：十进制字符串

```python
print(int("1111", 10))
```

讲解：十进制 `1111` 就是整数 `1111`。

### 示例 3：十六进制小写也可以

```python
print(int("ff", 16))
```

讲解：十六进制中 `A-F` 大小写都可以。

---

## 11. 自动识别进制：base=0

当 `base=0` 时，Python 会根据字符串前缀自动判断进制。

常见前缀：

- `0b`：二进制。
- `0o`：八进制。
- `0x`：十六进制。

### 示例 1：自动识别二进制

```python
print(int("0b1010", 0))
```

讲解：`0b` 表示二进制，结果是 `10`。

### 示例 2：自动识别八进制

```python
print(int("0o17", 0))
```

讲解：`0o` 表示八进制，结果是 `15`。

### 示例 3：自动识别十六进制

```python
print(int("0xFF", 0))
```

讲解：`0x` 表示十六进制，结果是 `255`。

## 12. int() 常见错误

### 示例 1：ValueError

```python
try:
    number = int("abc")
    print(number)
except ValueError:
    print("转换失败：内容不是合法整数")
```

讲解：字符串内容不符合整数格式时，会出现 `ValueError`。

### 示例 2：TypeError

```python
try:
    number = int(None)
    print(number)
except TypeError:
    print("转换失败：None 不能转换成整数")
```

讲解：传入的类型不合适时，可能出现 `TypeError`。

### 示例 3：进制不匹配

```python
try:
    number = int("102", 2)
    print(number)
except ValueError:
    print("转换失败：二进制中不能出现 2")
```

讲解：二进制只能包含 `0` 和 `1`。

## 13. 用 try except 处理用户输入

写程序时，不能假设用户一定输入正确内容。

### 示例 1：输入年龄

```python
try:
    age = int(input("请输入年龄："))
    print("明年年龄：", age + 1)
except ValueError:
    print("年龄必须是整数")
```

讲解：如果用户输入文字，程序不会崩溃，而是给出提示。

### 示例 2：循环直到输入正确

```python
while True:
    try:
        score = int(input("请输入分数："))
        break
    except ValueError:
        print("请输入整数分数")
print("你的分数是：", score)
```

讲解：这种写法适合必须得到合法整数的场景。

### 示例 3：限制范围

```python
while True:
    try:
        score = int(input("请输入 0 到 100 的分数："))
        if 0 <= score <= 100:
            break
        else:
            print("分数范围不正确")
    except ValueError:
        print("请输入整数")
print("有效分数：", score)
```

讲解：转换成功后，还要检查数字是否在合理范围内。

## 14. int() 在算法中的应用

### 示例 1：统计输入数字总和

```python
total = 0
for i in range(5):
    number = int(input("请输入整数："))
    total = total + number
print(total)
```

讲解：每次输入都要转成整数后才能累加。

### 示例 2：处理成绩字符串

```python
data = "88,95,76,90"
parts = data.split(",")
scores = []
for part in parts:
    scores.append(int(part))
print(sum(scores) / len(scores))
```

讲解：把一串成绩文本拆分，再逐个转换成整数。

### 示例 3：列表推导式转换

```python
data = "88,95,76,90"
scores = [int(part) for part in data.split(",")]
print(scores)
```

讲解：列表推导式可以让批量转换更简洁。

## 15. int() 和数学取整相关函数

Python 中和整数处理相关的工具不止 `int()`。

### 示例 1：int 截断

```python
print(int(3.9))
print(int(-3.9))
```

讲解：`int()` 去掉小数部分，向 0 截断。

### 示例 2：round 四舍五入附近取整

```python
print(round(3.9))
print(round(3.1))
```

讲解：`round()` 返回最接近的整数。

### 示例 3：// 整除

```python
print(17 // 5)
print(17 % 5)
```

讲解：`//` 得到商，`%` 得到余数。分糖果、分页、分组时经常用。

---

## 16. 易错点总结

1. `input()` 得到的是字符串，不是整数。
2. `int("3.14")` 会报错，应该先 `float("3.14")`。
3. `int(3.99)` 得到 `3`，不是 `4`。
4. `int(-3.99)` 得到 `-3`，因为它向 0 截断。
5. `int("102", 2)` 会报错，因为二进制没有数字 2。
6. 字符串中带单位、逗号、中文时，不能直接转换。
7. 用户输入要用 `try except` 保护。
