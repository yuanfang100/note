# 07. 数据容器概览：列表、字典、元组

当程序要处理多个数据时，只靠普通变量会很不方便。Python 提供了多种数据容器，其中最常用的是列表、字典和元组。

这一章先建立整体认识，后面的第 11、12、13 章会分别深入学习。

本章目标：

1. 知道列表、字典、元组分别适合保存什么数据。
2. 理解可变和不可变的区别。
3. 能用容器表示现实中的数据。
4. 能遍历容器并做简单统计。
5. 为后续专题章节建立知识框架。

---

## 1. 为什么需要数据容器

如果一个班有 40 个成绩，写 40 个变量非常麻烦：

```python
score1 = 80
score2 = 90
score3 = 75
```

更好的方式是把它们放进一个容器：

```python
scores = [80, 90, 75]
```

### 示例 1：保存多个成绩

```python
scores = [80, 90, 75, 88]
print(scores)
```

讲解：列表适合保存一组有顺序的数据。

### 示例 2：保存学生信息

```python
student = {"name": "李华", "age": 13, "score": 92}
print(student)
```

讲解：字典适合保存带名称的数据。

### 示例 3：保存坐标

```python
point = (10, 20)
print(point)
```

讲解：元组适合保存不希望随意修改的一组数据。

## 2. 列表 list

列表使用方括号 `[]`，可以修改。

### 示例 1：创建列表

```python
subjects = ["语文", "数学", "英语"]
print(subjects)
```

讲解：列表可以保存多个同类数据。

### 示例 2：添加元素

```python
subjects = ["语文", "数学"]
subjects.append("英语")
print(subjects)
```

讲解：`append()` 会在列表末尾添加元素。

### 示例 3：遍历列表

```python
subjects = ["语文", "数学", "英语"]
for subject in subjects:
    print(subject)
```

讲解：循环可以逐个处理列表元素。

---

## 3. 字典 dict

字典使用大括号 `{}`，保存键值对。

### 示例 1：创建字典

```python
student = {"name": "王宁", "grade": "初二", "score": 88}
print(student)
```

讲解：`name`、`grade`、`score` 是键，对应的数据是值。

### 示例 2：读取值

```python
student = {"name": "王宁", "grade": "初二", "score": 88}
print(student["name"])
```

讲解：通过键可以读取对应的值。

### 示例 3：修改值

```python
student = {"name": "王宁", "score": 88}
student["score"] = 95
print(student)
```

讲解：字典的值可以通过键修改。

---

## 4. 元组 tuple

元组使用小括号 `()`，创建后不能修改。

### 示例 1：坐标

```python
point = (3, 5)
print(point[0])
print(point[1])
```

讲解：坐标一旦创建，通常不希望随意修改，适合用元组。

### 示例 2：日期

```python
date = (2026, 6, 27)
print(date)
```

讲解：年、月、日可以作为一个整体保存。

### 示例 3：函数返回多个值

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)

result = get_min_max([3, 8, 1, 9])
print(result)
```

讲解：函数返回多个值时，实际常常返回一个元组。

## 5. 可变与不可变

列表和字典是可变对象，元组和字符串是不可变对象。

### 示例 1：列表可变

```python
numbers = [1, 2, 3]
numbers[0] = 100
print(numbers)
```

讲解：列表中的元素可以被修改。

### 示例 2：字典可变

```python
student = {"name": "李华", "score": 80}
student["score"] = 90
print(student)
```

讲解：字典中的值可以被修改。

### 示例 3：元组不可变

```python
point = (1, 2)
# point[0] = 100
print(point)
```

讲解：如果取消注释修改元组元素，会报错。

## 6. 容器嵌套

真实数据经常是多层结构。

### 示例 1：列表中放字典

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
print(students)
```

讲解：一个列表保存多个学生，每个学生用字典表示。

### 示例 2：遍历嵌套数据

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
for student in students:
    print(student["name"], student["score"])
```

讲解：先取出学生字典，再读取字典中的字段。

### 示例 3：统计平均分

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
total = 0
for student in students:
    total = total + student["score"]
print(total / len(students))
```

讲解：容器嵌套可以表示更真实的数据。
