算法是解决问题的明确步骤。初中阶段学习算法，不需要一开始追求很难的题，而要先熟练掌握：求和、计数、查找、最大最小、排序、筛选。

1. 理解算法和数据处理的关系。
2. 掌握求和、平均值、计数。
3. 掌握查找、筛选、最大最小。
4. 理解简单排序思想。
5. 能处理学生成绩这类常见数据。

## 1. 算法的基本思想

算法要求步骤清楚、结果明确、可以执行。

### 示例 1：求长方形面积

```python
length = 8
width = 5
area = length * width
print(area)
```

讲解：公式就是一种算法。

### 示例 2：判断偶数

```python
number = 18
if number % 2 == 0:
    print("偶数")
else:
    print("奇数")
```

讲解：通过余数判断奇偶。

### 示例 3：求两个数最大值

```python
a = 12
b = 9
if a > b:
    print(a)
else:
    print(b)
```

讲解：比较是很多算法的基础。

## 2. 求和与平均值

### 示例 1：列表求和

```python
scores = [80, 90, 75, 88]
total = 0
for score in scores:
    total = total + score
print(total)
```

讲解：累加变量通常从 0 开始。

### 示例 2：平均值

```python
scores = [80, 90, 75, 88]
average = sum(scores) / len(scores)
print(average)
```

讲解：Python 内置 `sum()` 和 `len()` 可以简化代码。

### 示例 3：输入多个数求和

```python
numbers = []
for i in range(5):
    number = int(input("请输入整数："))
    numbers.append(number)
print(sum(numbers))
```

讲解：可以边输入边保存，再统一处理。

## 3. 计数

计数用于统计符合条件的数据数量。

### 示例 1：统计及格人数

```python
scores = [55, 60, 73, 91, 48]
count = 0
for score in scores:
    if score >= 60:
        count = count + 1
print(count)
```

讲解：每遇到一个符合条件的数据，计数器加 1。

### 示例 2：统计偶数个数

```python
numbers = [1, 2, 3, 4, 5, 6]
count = 0
for number in numbers:
    if number % 2 == 0:
        count = count + 1
print(count)
```

讲解：条件可以换成任何规则。

### 示例 3：统计字符出现次数

```python
text = "programming"
count = 0
for char in text:
    if char == "g":
        count = count + 1
print(count)
```

讲解：字符串也能被遍历。

## 4. 最大值与最小值

### 示例 1：使用内置函数

```python
numbers = [12, 5, 27, 9]
print(max(numbers))
print(min(numbers))
```

讲解：Python 提供了方便的最大最小函数。

### 示例 2：手写最大值

```python
numbers = [12, 5, 27, 9]
max_number = numbers[0]
for number in numbers:
    if number > max_number:
        max_number = number
print(max_number)
```

讲解：理解这个过程很重要，很多复杂算法也使用类似思想。

### 示例 3：找最高分学生

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
best = students[0]
for student in students:
    if student["score"] > best["score"]:
        best = student
print(best["name"], best["score"])
```

讲解：最大值不一定只是数字，也可以是某条记录。

## 5. 查找与筛选

### 示例 1：查找目标

```python
names = ["李华", "王宁", "赵敏"]
target = "王宁"
if target in names:
    print("找到了")
else:
    print("没找到")
```

讲解：`in` 可以判断元素是否存在。

### 示例 2：手写查找

```python
names = ["李华", "王宁", "赵敏"]
target = "赵敏"
found = False
for name in names:
    if name == target:
        found = True
        break
print(found)
```

讲解：`found` 用来保存查找结果。

### 示例 3：筛选优秀成绩

```python
scores = [55, 60, 73, 91, 98]
excellent = []
for score in scores:
    if score >= 90:
        excellent.append(score)
print(excellent)
```

讲解：筛选常用一个新列表保存结果。

## 6. 排序

排序是把数据按规则排列。

### 示例 1：升序排序

```python
numbers = [5, 2, 9, 1]
numbers.sort()
print(numbers)
```

讲解：`sort()` 会修改原列表。

### 示例 2：降序排序

```python
numbers = [5, 2, 9, 1]
numbers.sort(reverse=True)
print(numbers)
```

讲解：`reverse=True` 表示从大到小。

### 示例 3：按学生成绩排序

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76}
]
students.sort(key=lambda student: student["score"], reverse=True)
print(students)
```

讲解：`key` 指定排序依据。

## 7. 冒泡排序思想

冒泡排序通过不断比较相邻元素，把较大的元素逐步移动到后面。

### 示例 1：交换变量

```python
a = 5
b = 2
a, b = b, a
print(a, b)
```

讲解：排序中经常需要交换两个元素。

### 示例 2：比较相邻元素

```python
numbers = [5, 2, 9]
if numbers[0] > numbers[1]:
    numbers[0], numbers[1] = numbers[1], numbers[0]
print(numbers)
```

讲解：如果前面比后面大，就交换位置。

### 示例 3：完整冒泡排序

```python
numbers = [5, 2, 9, 1]
for i in range(len(numbers)):
    for j in range(0, len(numbers) - 1 - i):
        if numbers[j] > numbers[j + 1]:
            numbers[j], numbers[j + 1] = numbers[j + 1], numbers[j]
print(numbers)
```

讲解：初学阶段重点理解思想，不必死记代码。
