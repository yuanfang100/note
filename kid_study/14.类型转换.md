# 14. 类型转换

类型转换是把一种数据类型转换成另一种数据类型。它在 Python 中非常常见，尤其是处理用户输入、文件内容、网络数据时。

本章目标：

1. 理解为什么需要类型转换。
2. 掌握 `int()`、`float()`、`str()`、`bool()`。
3. 掌握列表、元组、集合之间的转换。
4. 理解隐式转换和显式转换。
5. 学会处理转换错误。

---

## 1. 为什么需要类型转换

用户输入、文件读取、网络返回的数据，经常是字符串。如果要计算，就必须转换成数字。

### 示例 1：input 得到字符串

```python
age = input("请输入年龄：")
print(type(age))
```

讲解：即使输入 `13`，`age` 也是字符串 `"13"`。

### 示例 2：字符串不能直接做数字加法

```python
age = "13"
# print(age + 1)
print(int(age) + 1)
```

讲解：字符串和整数不能直接相加，需要先转换。

### 示例 3：文件数据也常是字符串

```python
line = "李华,88"
name, score_text = line.split(",")
score = int(score_text)
print(name, score + 5)
```

讲解：从文本拆出来的分数是字符串，要转换成整数才能计算。

---

## 2. int 转整数

`int()` 可以把合适的数据转换成整数。

### 示例 1：字符串转整数

```python
number_text = "123"
number = int(number_text)
print(number + 1)
```

讲解：`"123"` 是内容像整数的字符串，可以转换。

### 示例 2：浮点数转整数

```python
value = 3.9
number = int(value)
print(number)
```

讲解：`int()` 转浮点数时会去掉小数部分，不是四舍五入。

### 示例 3：输入整数

```python
a = int(input("请输入第一个整数："))
b = int(input("请输入第二个整数："))
print(a + b)
```

讲解：做计算器时，输入转换非常常见。

---

## 3. float 转浮点数

`float()` 可以转换小数。

### 示例 1：字符串转小数

```python
height_text = "1.68"
height = float(height_text)
print(height)
```

讲解：身高、体重、价格常使用浮点数。

### 示例 2：整数转浮点数

```python
number = 5
value = float(number)
print(value)
```

讲解：整数可以转换成浮点数。

### 示例 3：BMI 计算

```python
height = float(input("身高，单位米："))
weight = float(input("体重，单位千克："))
bmi = weight / (height ** 2)
print(f"{bmi:.2f}")
```

讲解：输入小数时必须使用 `float()`。

---

## 4. str 转字符串

`str()` 可以把其他类型转换为字符串。

### 示例 1：数字转字符串拼接

```python
age = 13
message = "年龄：" + str(age)
print(message)
```

讲解：字符串拼接时，数字要先转成字符串。

### 示例 2：布尔值转字符串

```python
is_passed = True
text = str(is_passed)
print(text)
print(type(text))
```

讲解：转换后 `True` 变成字符串 `"True"`。

### 示例 3：列表转字符串

```python
scores = [88, 95, 76]
text = str(scores)
print(text)
```

讲解：`str()` 可以得到列表的字符串表现形式，但不适合复杂数据长期保存。

---

## 5. bool 转布尔值

`bool()` 可以把数据转换为真假。

常见规则：

- 数字 0 是 `False`，非 0 是 `True`。
- 空字符串 `""` 是 `False`，非空字符串是 `True`。
- 空列表 `[]` 是 `False`，非空列表是 `True`。

### 示例 1：数字转布尔值

```python
print(bool(0))
print(bool(1))
print(bool(-5))
```

讲解：只有 0 转为 `False`。

### 示例 2：字符串转布尔值

```python
print(bool(""))
print(bool("hello"))
print(bool("False"))
```

讲解：注意字符串 `"False"` 不是空字符串，所以结果是 `True`。

### 示例 3：列表转布尔值

```python
tasks = []
if tasks:
    print("有任务")
else:
    print("没有任务")
```

讲解：空列表在条件判断中等价于 `False`。

## 6. 容器类型转换

列表、元组、集合可以互相转换。

### 示例 1：元组转列表

```python
numbers = (1, 2, 3)
numbers_list = list(numbers)
numbers_list.append(4)
print(numbers_list)
```

讲解：元组不可修改，转成列表后可以添加元素。

### 示例 2：列表转元组

```python
numbers = [1, 2, 3]
numbers_tuple = tuple(numbers)
print(numbers_tuple)
```

讲解：如果数据不希望被修改，可以转成元组。

### 示例 3：列表转集合去重

```python
numbers = [1, 2, 2, 3, 3, 3]
unique_numbers = set(numbers)
print(unique_numbers)
```

讲解：集合 `set` 不保留重复元素。

## 7. 字符串和列表转换

### 示例 1：split 字符串转列表

```python
text = "语文,数学,英语"
subjects = text.split(",")
print(subjects)
```

讲解：`split()` 按分隔符拆分字符串。

### 示例 2：join 列表转字符串

```python
subjects = ["语文", "数学", "英语"]
text = ",".join(subjects)
print(text)
```

讲解：`join()` 把字符串列表连接成一个字符串。

### 示例 3：逐字符转换

```python
word = "Python"
chars = list(word)
print(chars)
```

讲解：`list()` 可以把字符串拆成字符列表。

## 8. 隐式转换和显式转换

显式转换是我们主动调用 `int()`、`float()` 等函数。隐式转换是 Python 在某些运算中自动完成。

### 示例 1：整数和浮点数运算

```python
result = 3 + 2.5
print(result)
print(type(result))
```

讲解：整数和浮点数一起计算，结果会变成浮点数。

### 示例 2：除法结果

```python
result = 10 / 2
print(result)
print(type(result))
```

讲解：普通除法 `/` 的结果是浮点数，即使能整除。

### 示例 3：显式转换更清楚

```python
age_text = "13"
age = int(age_text)
print(age + 1)
```

讲解：涉及输入和文本数据时，应该明确转换。

## 9. 转换错误处理

不是所有字符串都能转换成数字。

### 示例 1：无法转换的字符串

```python
text = "abc"
# number = int(text)
print(text)
```

讲解：`int("abc")` 会报 `ValueError`。

### 示例 2：使用 try except

```python
try:
    number = int(input("请输入整数："))
    print(number * 2)
except ValueError:
    print("输入内容不是整数")
```

讲解：异常处理可以让程序更友好。

### 示例 3：循环直到输入正确

```python
while True:
    try:
        age = int(input("请输入年龄："))
        break
    except ValueError:
        print("请重新输入整数")
print("年龄：", age)
```

讲解：这种写法适合需要可靠输入的程序。
