# 08. 文件、异常与调试

真实程序经常需要保存数据，也经常会遇到错误。会读写文件、会处理异常、会调试，是从“能写练习题”走向“能写完整程序”的重要一步。

本章目标：

1. 掌握文本文件读写。
2. 理解文件模式 `r`、`w`、`a`。
3. 掌握 `try except` 异常处理。
4. 学会使用 `print()` 和分步法调试。
5. 能保存和读取简单数据。

---

## 1. 文件是什么

文件是保存在硬盘中的数据。Python 可以通过文件保存程序运行结果，也可以从文件读取数据。

### 示例 1：常见文件

```text
notes.txt
scores.csv
main.py
image.jpg
```

讲解：不同后缀通常表示不同类型的文件。

### 示例 2：文本文件内容

```text
李华,88
王宁,95
赵敏,76
```

讲解：文本文件可以保存结构化数据。

### 示例 3：Python 文件

```text
student_system.py
```

讲解：`.py` 文件保存 Python 代码，本身也是文本文件。

## 2. 写入文件

写入文件使用 `open()`，推荐配合 `with`。

### 示例 1：写入一行文字

```python
with open("note.txt", "w", encoding="utf-8") as file:
    file.write("今天学习文件操作")
```

讲解：`w` 是写入模式，如果文件存在，会覆盖原内容。

### 示例 2：写入多行

```python
with open("plan.txt", "w", encoding="utf-8") as file:
    file.write("学习变量\n")
    file.write("学习循环\n")
    file.write("学习函数\n")
```

讲解：`\n` 表示换行。

### 示例 3：写入列表内容

```python
subjects = ["语文", "数学", "英语"]
with open("subjects.txt", "w", encoding="utf-8") as file:
    for subject in subjects:
        file.write(subject + "\n")
```

讲解：循环可以把一组数据写入文件。

## 3. 读取文件

读取模式是 `r`。

### 示例 1：读取全部内容

```python
with open("note.txt", "r", encoding="utf-8") as file:
    content = file.read()
print(content)
```

讲解：`read()` 会一次读取全部内容。

### 示例 2：逐行读取

```python
with open("subjects.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

讲解：逐行读取适合处理大文件，`strip()` 去掉换行。

### 示例 3：读取成列表

```python
with open("subjects.txt", "r", encoding="utf-8") as file:
    lines = file.readlines()
print(lines)
```

讲解：`readlines()` 会把每一行放进列表。

---

## 4. 追加文件

追加模式是 `a`，会把内容添加到文件末尾。

### 示例 1：追加日记

```python
with open("diary.txt", "a", encoding="utf-8") as file:
    file.write("今天完成了 Python 练习\n")
```

讲解：追加不会清空原来的内容。

### 示例 2：追加成绩

```python
name = "李华"
score = 88
with open("scores.txt", "a", encoding="utf-8") as file:
    file.write(f"{name},{score}\n")
```

讲解：用逗号分隔字段，方便之后读取和拆分。

### 示例 3：循环追加

```python
records = ["王宁,95", "赵敏,76"]
with open("scores.txt", "a", encoding="utf-8") as file:
    for record in records:
        file.write(record + "\n")
```

讲解：可以一次追加多条记录。

## 5. 异常处理

异常是程序运行时出现的问题。`try except` 可以让程序遇到问题时给出友好提示，而不是直接崩溃。

### 示例 1：处理输入不是数字

```python
try:
    age = int(input("请输入年龄："))
    print(age + 1)
except ValueError:
    print("年龄必须是数字")
```

讲解：如果输入 `abc`，`int()` 会失败，程序进入 `except`。

### 示例 2：处理文件不存在

```python
try:
    with open("missing.txt", "r", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("文件不存在")
```

讲解：读取文件前，文件可能不存在。

### 示例 3：处理除以 0

```python
try:
    a = 10
    b = 0
    print(a / b)
except ZeroDivisionError:
    print("除数不能为 0")
```

讲解：异常处理要针对可能发生的问题。

## 6. 调试方法

调试是找到并修复程序问题的过程。

### 示例 1：打印变量

```python
price = 8
count = 5
print("price =", price)
print("count =", count)
total = price * count
print(total)
```

讲解：输出变量可以确认程序中间状态。

### 示例 2：定位执行位置

```python
print("程序开始")
numbers = [1, 2, 3]
print("列表创建完成")
print(sum(numbers))
print("程序结束")
```

讲解：如果程序卡住或报错，可以用提示语定位运行到了哪里。

### 示例 3：检查循环过程

```python
total = 0
for number in [1, 2, 3]:
    total = total + number
    print("当前 number =", number, "total =", total)
```

讲解：循环中打印变量，能看清每一步变化。
