# 06. 字符串与文本处理

字符串是程序中最常见的数据类型之一。账号、姓名、文章、文件路径、网页内容、命令输入，本质上都可能以字符串形式出现。

本章目标：

1. 理解字符串的定义和不可变特点。
2. 掌握索引、切片、遍历。
3. 掌握查找、替换、分割、拼接。
4. 学会格式化输出。
5. 能处理简单文本数据。

---

## 1. 字符串基础

字符串是由字符组成的序列，使用单引号或双引号表示。

### 示例 1：单引号和双引号

```python
name1 = "Python"
name2 = 'Python'
print(name1)
print(name2)
```

讲解：单引号和双引号都可以表示字符串，但开始和结束必须一致。

### 示例 2：字符串中包含数字

```python
student_id = "2026001"
print(student_id)
```

讲解：学号虽然由数字组成，但通常不参与数学计算，所以适合用字符串。

### 示例 3：多行字符串

```python
text = """第一行
第二行
第三行"""
print(text)
```

讲解：三引号可以表示多行字符串。

---

## 2. 索引

字符串中的每个字符都有位置编号，称为索引。Python 索引从 0 开始。

### 示例 1：读取第一个字符

```python
word = "Python"
print(word[0])
```

讲解：索引 0 表示第一个字符 `P`。

### 示例 2：读取最后一个字符

```python
word = "Python"
print(word[-1])
```

讲解：索引 `-1` 表示最后一个字符。

### 示例 3：索引越界

```python
word = "Python"
# print(word[10])
print(len(word))
```

讲解：不能访问不存在的位置，否则会报 `IndexError`。

---

## 3. 切片

切片用于获取字符串的一部分。

格式：

```python
字符串[开始:结束:步长]
```

结束位置不包含在结果中。

### 示例 1：取前三个字符

```python
word = "Python"
print(word[0:3])
```

讲解：结果是 `Pyt`，包含索引 0、1、2。

### 示例 2：省略开始或结束

```python
word = "Python"
print(word[:2])
print(word[2:])
```

讲解：省略开始表示从头开始，省略结束表示到末尾。

### 示例 3：反转字符串

```python
word = "Python"
print(word[::-1])
```

讲解：步长为 `-1` 可以从后往前取字符。

---

## 4. 遍历字符串

字符串可以用 `for` 循环逐个字符处理。

### 示例 1：逐个输出字符

```python
word = "Python"
for char in word:
    print(char)
```

讲解：每次循环取出一个字符。

### 示例 2：统计字母出现次数

```python
text = "banana"
count = 0
for char in text:
    if char == "a":
        count = count + 1
print(count)
```

讲解：计数器可以统计目标字符出现次数。

### 示例 3：统计数字字符

```python
text = "abc123xyz45"
count = 0
for char in text:
    if char.isdigit():
        count = count + 1
print(count)
```

讲解：`isdigit()` 可以判断字符是否为数字。

## 5. 查找和判断

### 示例 1：in 判断包含

```python
email = "student@example.com"
print("@" in email)
```

讲解：判断邮箱字符串中是否包含 `@`。

### 示例 2：find 查找位置

```python
text = "I like Python"
print(text.find("Python"))
print(text.find("Java"))
```

讲解：找到了返回位置，找不到返回 `-1`。

### 示例 3：startswith 和 endswith

```python
filename = "report.pdf"
print(filename.startswith("report"))
print(filename.endswith(".pdf"))
```

讲解：常用于判断前缀和后缀。

---

## 6. 替换、分割和去空格

### 示例 1：replace 替换

```python
text = "I like Java"
new_text = text.replace("Java", "Python")
print(new_text)
```

讲解：`replace()` 会返回替换后的新字符串。

### 示例 2：split 分割

```python
data = "张三,85,初二"
parts = data.split(",")
print(parts)
```

讲解：`split()` 可以把字符串按指定分隔符拆成列表。

### 示例 3：strip 去空格

```python
name = "  李华  "
print(name.strip())
```

讲解：`strip()` 去掉字符串两端空白，常用于处理用户输入。

---

## 7. 字符串格式化

格式化可以把变量放进字符串中。推荐初学者优先使用 f-string。

### 示例 1：f-string 基础

```python
name = "李华"
score = 92
print(f"{name} 的成绩是 {score}")
```

讲解：在字符串前加 `f`，花括号里可以放变量。

### 示例 2：格式化小数

```python
average = 88.6666
print(f"平均分：{average:.2f}")
```

讲解：`:.2f` 表示保留两位小数。

### 示例 3：表达式格式化

```python
a = 12
b = 8
print(f"{a} + {b} = {a + b}")
```

讲解：花括号中可以写简单表达式。
