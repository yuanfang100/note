## 1. 项目一：BMI 计算器

BMI = 体重千克 / 身高米的平方。

### 示例 1：固定数据版本

```python
height = 1.70
weight = 60
bmi = weight / (height ** 2)
print(bmi)
```

讲解：先用固定数据验证公式。

### 示例 2：用户输入版本

```python
height = float(input("请输入身高，单位米："))
weight = float(input("请输入体重，单位千克："))
bmi = weight / (height ** 2)
print(f"BMI = {bmi:.2f}")
```

讲解：输入的小数要用 `float()` 转换。

### 示例 3：加入判断

```python
height = float(input("身高："))
weight = float(input("体重："))
bmi = weight / (height ** 2)
if bmi < 18.5:
    print("偏瘦")
elif bmi < 24:
    print("正常")
else:
    print("偏重")
print(f"BMI = {bmi:.2f}")
```

讲解：项目通常由输入、计算、判断、输出组成。

## 2. 项目二：成绩统计器

### 示例 1：计算平均分

```python
scores = [88, 95, 76, 60, 91]
average = sum(scores) / len(scores)
print(f"平均分：{average:.2f}")
```

讲解：`sum()` 求总分，`len()` 求人数。

### 示例 2：统计等级

```python
scores = [88, 95, 76, 60, 91]
excellent_count = 0
pass_count = 0
for score in scores:
    if score >= 90:
        excellent_count = excellent_count + 1
    if score >= 60:
        pass_count = pass_count + 1
print("优秀人数：", excellent_count)
print("及格人数：", pass_count)
```

讲解：可以在一次循环中统计多个结果。

### 示例 3：封装成函数

```python
def analyze_scores(scores):
    average = sum(scores) / len(scores)
    highest = max(scores)
    lowest = min(scores)
    return average, highest, lowest

result = analyze_scores([88, 95, 76, 60, 91])
print(result)
```

讲解：函数可以让统计逻辑更容易复用。

## 3. 项目三：猜数字游戏

### 示例 1：基础版本

```python
answer = 7
guess = int(input("猜一个数字："))
if guess == answer:
    print("猜对了")
else:
    print("猜错了")
```

讲解：先做一个最小可运行版本。

### 示例 2：循环版本

```python
answer = 7
while True:
    guess = int(input("猜数字："))
    if guess == answer:
        print("猜对了")
        break
    elif guess < answer:
        print("太小了")
    else:
        print("太大了")
```

讲解：`while True` 配合 `break` 常用于游戏循环。

### 示例 3：随机版本

```python
import random

answer = random.randint(1, 100)
count = 0
while True:
    guess = int(input("猜 1 到 100 的数字："))
    count = count + 1
    if guess == answer:
        print(f"猜对了，共猜了 {count} 次")
        break
    elif guess < answer:
        print("太小了")
    else:
        print("太大了")
```

讲解：`random` 模块让游戏每次不同。

## 4. 项目四：通讯录

### 示例 1：用字典保存联系人

```python
contacts = {
    "李华": "13800000001",
    "王宁": "13800000002"
}
print(contacts)
```

讲解：姓名作为键，电话作为值。

### 示例 2：查询联系人

```python
contacts = {
    "李华": "13800000001",
    "王宁": "13800000002"
}
name = input("请输入姓名：")
if name in contacts:
    print(contacts[name])
else:
    print("未找到")
```

讲解：字典查询速度快，适合通讯录。

### 示例 3：菜单版本

```python
contacts = {}
while True:
    print("1. 添加联系人")
    print("2. 查询联系人")
    print("3. 退出")
    choice = input("请选择：")

    if choice == "1":
        name = input("姓名：")
        phone = input("电话：")
        contacts[name] = phone
    elif choice == "2":
        name = input("姓名：")
        print(contacts.get(name, "未找到"))
    elif choice == "3":
        break
    else:
        print("输入无效")
```

讲解：菜单循环是很多命令行小程序的基础结构。

## 5. 项目五：保存成绩到文件

### 示例 1：写入成绩

```python
with open("scores.txt", "w", encoding="utf-8") as file:
    file.write("李华,88\n")
    file.write("王宁,95\n")
```

讲解：每行保存一个学生成绩。

### 示例 2：读取成绩

```python
with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())
```

讲解：`strip()` 去掉行尾换行符。

### 示例 3：读取并计算平均分

```python
scores = []
with open("scores.txt", "r", encoding="utf-8") as file:
    for line in file:
        name, score_text = line.strip().split(",")
        scores.append(int(score_text))
print(sum(scores) / len(scores))
```

讲解：从文件读取的是字符串，计算前要转换成整数。

## 6. 最终挑战：班级成绩系统

要求：

1. 使用列表和字典保存至少 5 个学生。
2. 输出所有学生。
3. 计算平均分。
4. 找出最高分学生。
5. 筛选优秀学生，标准是大于等于 90。
6. 把结果写入文件。

参考代码：

```python
students = [
    {"name": "李华", "score": 88},
    {"name": "王宁", "score": 95},
    {"name": "赵敏", "score": 76},
    {"name": "陈晨", "score": 91},
    {"name": "周杰", "score": 59}
]

total = 0
best = students[0]
excellent = []

for student in students:
    total = total + student["score"]
    if student["score"] > best["score"]:
        best = student
    if student["score"] >= 90:
        excellent.append(student)

average = total / len(students)

with open("result.txt", "w", encoding="utf-8") as file:
    file.write(f"平均分：{average:.2f}\n")
    file.write(f"最高分：{best['name']} {best['score']}\n")
    file.write("优秀学生：\n")
    for student in excellent:
        file.write(f"{student['name']} {student['score']}\n")
```

讲解：这个项目综合使用了容器、循环、条件、字符串格式化和文件写入。
