# 02. Python 环境、运行方式与第一批程序

学 Python 时，不能只会“复制代码”。你需要理解 Python 程序如何保存、如何运行、如何输出结果，以及出现错误时应该怎样阅读错误信息。

本章目标：

1. 理解 Python 解释器的作用。
2. 知道 `.py` 文件是什么。
3. 熟练使用 `print()` 输出内容。
4. 理解程序从上到下执行。
5. 学会写注释和阅读简单报错。

---

## 1. Python 是解释型语言

Python 程序通常由 Python 解释器执行。解释器可以理解 `.py` 文件中的代码，并把它转换成计算机能执行的操作。

### 示例 1：一个 Python 文件

```text
hello.py
```

讲解：后缀 `.py` 表示这是 Python 源代码文件。

### 示例 2：文件中的代码

```python
print("Hello, Python")
```

讲解：运行这个文件时，Python 解释器会执行 `print()`。

### 示例 3：命令行运行

```bash
python hello.py
```

讲解：在安装并配置好 Python 后，可以通过命令运行文件。

---

## 2. print 输出

`print()` 用于把内容输出到屏幕或终端，是初学时最常用的调试工具。

### 示例 1：输出字符串

```python
print("我正在学习 Python")
```

讲解：字符串要写在引号中。

### 示例 2：输出数字计算

```python
print(12 + 8)
print(6 * 7)
print(20 / 4)
```

讲解：Python 会先计算表达式，再输出结果。

### 示例 3：一次输出多个值

```python
name = "李明"
age = 13
print("姓名：", name, "年龄：", age)
```

讲解：`print()` 中可以用逗号分隔多个内容，输出时自动加空格。

---

## 3. 程序执行顺序

Python 默认从上到下逐行执行。

### 示例 1：顺序输出

```python
print("第一步：准备数据")
print("第二步：进行计算")
print("第三步：输出结果")
```

讲解：输出顺序和代码顺序一致。

### 示例 2：变量先定义再使用

```python
score = 90
print(score)
```

讲解：变量必须先赋值，后使用。

### 示例 3：错误顺序

```python
# print(score)
score = 90
```

讲解：如果取消注释第一行，会因为 `score` 还不存在而报错。

## 4. 注释

注释是写给人看的说明，Python 不会执行注释。单行注释以 `#` 开头。

### 示例 1：说明代码目的

```python
# 计算两个分数的平均值
a = 80
b = 90
print((a + b) / 2)
```

讲解：好的注释解释“为什么这样做”，而不是重复代码本身。

### 示例 2：临时关闭代码

```python
print("这一行会运行")
# print("这一行暂时不运行")
```

讲解：调试时可以临时注释某些代码。

### 示例 3：用注释规划程序

```python
# 1. 输入半径
# 2. 计算圆面积
# 3. 输出结果
radius = 3
area = 3.14 * radius * radius
print(area)
```

讲解：先写思路，再写代码，是很好的习惯。

## 5. 基本输入 input

`input()` 可以接收用户输入。注意：`input()` 得到的内容一定是字符串。

### 示例 1：输入姓名

```python
name = input("请输入姓名：")
print("你好，" + name)
```

讲解：输入的文字会保存到变量 `name`。

### 示例 2：输入年龄

```python
age = input("请输入年龄：")
print("你输入的年龄是：", age)
```

讲解：这里的 `age` 是字符串，不是整数。

### 示例 3：输入数字并转换

```python
number = int(input("请输入一个整数："))
print(number + 10)
```

讲解：如果要做数学计算，需要使用 `int()` 把输入转换为整数。

---

## 6. 常见报错

报错并不可怕，它是 Python 告诉你程序哪里不符合规则。

### 示例 1：SyntaxError 语法错误

```python
# print("hello"
print("hello")
```

讲解：被注释的写法少了右括号，会产生语法错误。

### 示例 2：NameError 名称错误

```python
# print(total)
total = 100
print(total)
```

讲解：变量使用前必须存在。

### 示例 3：ValueError 值错误

```python
text = "123"
number = int(text)
print(number + 1)
```

讲解：`int("123")` 可以成功，但 `int("abc")` 会失败。
