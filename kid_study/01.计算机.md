## 1. 计算机系统是什么

计算机不是单独指一台台式电脑。手机、平板、智能手表、路由器、自动售票机、扫码枪、服务器，本质上都可以看作计算机系统。

一个计算机系统通常包括三部分：

- 硬件：能摸到的设备，比如 CPU、内存、硬盘、键盘、屏幕。
- 软件：能运行的程序，比如操作系统、浏览器、游戏、Python 程序。
- 数据：被软件处理的信息，比如文字、图片、成绩、坐标、视频。

### 示例 1：手机拍照

```text
硬件：摄像头、屏幕、存储芯片
软件：相机 App、相册 App、操作系统
数据：照片文件、拍摄时间、地点信息
```

讲解：拍照不是摄像头单独完成的，而是硬件、软件和数据一起工作。

### 示例 2：学校成绩系统

```text
硬件：服务器、老师电脑、学生查询设备
软件：成绩录入系统、数据库程序
数据：学生姓名、班级、科目、分数
```

讲解：真实系统里，程序最重要的工作之一就是管理和处理数据。

### 示例 3：Python 计算程序

```python
score1 = 90
score2 = 86
average = (score1 + score2) / 2
print(average)
```

讲解：这段代码把数字作为数据，使用 Python 程序进行计算，最后把结果输出到屏幕。

## 2. 输入、处理、输出、存储

大多数计算机任务可以用四个词概括：

1. 输入：接收信息。
2. 处理：按照规则计算或判断。
3. 输出：给出结果。
4. 存储：把数据保存起来，之后还能继续使用。

### 示例 1：计算器

```text
输入：用户输入 18 + 24
处理：计算加法
输出：显示 42
存储：可以把历史记录保存起来
```

讲解：计算器很简单，但已经包含了程序的基本过程。

### 示例 2：登录系统

```text
输入：账号和密码
处理：检查账号是否存在、密码是否正确
输出：登录成功或登录失败
存储：账号信息保存在数据库中
```

讲解：程序不只是计算数字，还会做比较、查找和判断。

### 示例 3：Python 输入与输出

```python
name = input("请输入姓名：")
print("欢迎你，" + name)
```

讲解：`input()` 是输入，字符串拼接是处理，`print()` 是输出。

## 3. 生活中常见的输入设备和输出设备

输入设备负责把人的动作、声音、图像、位置、数字等信息送进计算机。输出设备负责把计算机处理后的结果显示、播放、打印或传递出来。

有些设备既可以输入，也可以输出，比如触摸屏：它能显示画面，这是输出；也能接收手指触摸，这是输入。

### 常见输入设备

- 键盘：输入文字、数字、快捷键。
- 鼠标：控制指针、点击按钮、拖动物体。
- 触摸板：笔记本电脑上常见，用手指控制指针。
- 触摸屏：手机、平板、自助点餐机上常见，用手指点击和滑动。
- 手写板：把手写文字、绘画动作输入电脑。
- 数位板：画画、设计、动画制作常用。
- 麦克风：输入声音，比如语音聊天、录音、语音识别。
- 摄像头：输入图像和视频，比如视频通话、人脸识别。
- 扫描仪：把纸质文件、照片扫描成电子文件。
- 条形码扫描器：超市收银、仓库管理常用。
- 二维码扫描器：扫码支付、扫码登录、扫码入库常用。
- 指纹识别器：输入指纹信息，用于解锁或身份验证。
- 人脸识别摄像头：输入面部图像，用于门禁、支付、考勤。
- 虹膜识别设备：输入眼睛虹膜信息，用于高安全身份验证。
- 游戏手柄：输入游戏操作，比如移动、跳跃、攻击。
- 摇杆：游戏机、模拟驾驶、无人机控制常用。
- 方向盘控制器：赛车游戏、驾驶模拟器常用。
- 体感设备：通过身体动作输入指令，比如运动游戏。
- 遥控器：电视、空调、投影仪、机顶盒常用。
- 读卡器：读取银行卡、校园卡、门禁卡、身份证等信息。
- 磁条读卡器：读取银行卡、会员卡等磁条信息。
- IC 卡/NFC 读取器：公交卡、门禁卡、手机 NFC 常用。
- GPS 接收器：输入位置信息。
- 温度传感器：输入温度数据。
- 湿度传感器：输入空气湿度数据。
- 光线传感器：输入环境亮度数据，手机自动调亮度会用到。
- 距离传感器：检测物体距离，机器人、手机常用。
- 压力传感器：电子秤、智能鞋垫、工业设备常用。
- 加速度传感器：手机横竖屏切换、运动手环计步常用。
- 陀螺仪：检测旋转方向，手机游戏、无人机常用。
- 电子秤：输入重量数据。
- 收银秤：输入重量并配合商品价格计算金额。
- 电子白板笔：输入书写和点击操作。
- MIDI 键盘：输入音乐按键数据，用于音乐制作。
- 语音助手设备：通过麦克风接收语音命令。
- 智能手环/手表传感器：输入心率、步数、睡眠等数据。

### 常见输出设备

- 显示器：输出文字、图片、视频、程序界面。
- 手机屏幕：输出 App 界面、消息、图片、视频。
- 平板屏幕：输出图像和交互界面。
- 投影仪：把画面投到幕布或墙上。

- 打印机：把电子文档输出到纸张上。

- 智能门锁电机：输出开锁或关锁动作。
- 无人机电机：根据控制程序输出飞行动作。
- 汽车仪表盘：输出速度、油量、电量、导航等信息。
- 医疗监护仪屏幕：输出心率、血压、血氧等结果。
- 智能家居设备：灯光亮灭、窗帘开合、空调调温都是输出动作。

### 同时具备输入和输出功能的设备

- 触摸屏：显示画面是输出，接收触摸是输入。
- 智能手机：屏幕、扬声器是输出；摄像头、麦克风、触摸屏、传感器是输入。

- 自助售票机：触摸屏输入选择，屏幕和票据打印输出结果。
- POS 收银机：扫码枪和键盘输入商品信息，小票打印机和屏幕输出结果。

## 4. CPU、内存和硬盘

理解 CPU、内存、硬盘的区别，对学习程序运行很有帮助。

- CPU：负责执行指令和计算，速度很快。
- 内存：保存正在运行的程序和临时数据，断电后数据通常会消失。
- 硬盘：长期保存文件，速度比内存慢，但断电后文件还在。

可以把它们想象成：

- CPU 是正在解题的人。
- 内存是桌面上摊开的草稿纸。
- 硬盘是书包里的书和笔记本。

### 示例 1：运行 Python 文件

```text
1. Python 文件保存在硬盘中
2. 运行时，系统把程序加载到内存
3. CPU 按顺序执行程序指令
4. 结果显示在屏幕上
```

讲解：程序不是“躺在文件里”就能工作，必须被加载并执行。

### 示例 2：变量保存在内存中

```python
age = 13
name = "小林"
print(name, age)
```

讲解：程序运行时，`age` 和 `name` 这些变量值会临时放在内存里。

### 示例 3：文件保存在硬盘中

```python
with open("note.txt", "w", encoding="utf-8") as file:
    file.write("今天学习了计算机基础")
```

讲解：变量通常是临时的，文件则可以长期保存到硬盘中。

## 5. 程序、指令和算法

程序是一组让计算机完成任务的指令。算法是解决问题的步骤。代码是用编程语言写出来的程序文本。

它们的关系可以这样理解：

```text
问题：求三个数的平均值
算法：先求和，再除以 3
代码：用 Python 把这个算法写出来
程序：代码运行起来后执行任务
```

### 示例 1：平均值算法

```python
a = 80
b = 90
c = 100
average = (a + b + c) / 3
print(average)
```

讲解：先求总分，再除以数量，这就是平均值算法。

### 示例 2：判断是否及格

```python
score = 72
if score >= 60:
    print("及格")
else:
    print("不及格")
```

讲解：程序可以根据条件选择不同路径。

### 示例 3：统计一组分数的总和

```python
scores = [80, 95, 70, 88]
total = 0
for score in scores:
    total = total + score
print(total)
```

讲解：重复处理一组数据时，循环比手写多行更清晰。

## 6. 二进制和数据表示

计算机底层使用二进制，也就是只用 `0` 和 `1` 表示信息。一个二进制位叫 bit，8 个 bit 通常组成 1 个 byte，也就是字节。

为什么计算机喜欢 0 和 1？因为硬件电路很适合表示两种状态：

- 有电 / 没电
- 高电压 / 低电压
- 真 / 假

### 示例 1：十进制和二进制

```text
十进制 0 -> 二进制 0
十进制 1 -> 二进制 1
十进制 2 -> 二进制 10
十进制 3 -> 二进制 11
十进制 4 -> 二进制 100
```

讲解：二进制也能表示所有数字，只是进位规则和十进制不同。

### 示例 2：Python 查看二进制

```python
print(bin(2))
print(bin(8))
print(bin(15))
```

讲解：`bin()` 可以把整数转换成二进制字符串，结果前面的 `0b` 表示这是二进制。

### 示例 3：字符也能编码

```python
print(ord("A"))
print(chr(65))
print(ord("中"))
```

讲解：计算机保存文字时，也会把字符转换成数字编码。

## 7. 操作系统和应用程序

操作系统，英文是 Operating System，常简称 OS。它是计算机中最重要的系统软件之一，负责管理硬件资源，并为应用程序提供运行环境。

如果把计算机想象成一所学校：

- 硬件像教室、桌椅、黑板、实验器材。
- 应用程序像不同课程的老师和活动。
- 操作系统像教务处和总管理员，负责安排资源、维持秩序、让大家能正常工作。

应用程序运行时，通常需要向操作系统申请资源，比如读取文件、使用网络、显示窗口。

操作系统主要负责：

1. 管理 CPU：决定哪些程序先运行，哪些程序后运行。
2. 管理内存：给正在运行的程序分配临时空间。
3. 管理文件：创建、读取、保存、删除文件。
4. 管理设备：控制键盘、鼠标、屏幕、打印机、摄像头等设备。
5. 管理用户界面：提供桌面、窗口、图标、菜单或命令行。
6. 管理权限：决定哪些用户能访问哪些文件和功能。
7. 管理网络：让计算机连接互联网或局域网。
8. 提供程序运行环境：让浏览器、游戏、微信、Python 等软件能够运行。

## 8. 编程思维：分解问题

编程最重要的能力不是背语法，而是把问题拆成清晰步骤。

比如“做一个成绩分析程序”，可以拆成：

1. 准备一组成绩。
2. 计算总分。
3. 计算平均分。
4. 找出最高分。
5. 统计及格人数。
6. 输出结果。

### 示例 1：先用文字写步骤

```text
目标：统计及格人数
1. 准备成绩列表
2. 准备计数器 count = 0
3. 逐个查看成绩
4. 如果成绩 >= 60，count 加 1
5. 输出 count
```

讲解：写代码前先写步骤，可以减少混乱。

### 示例 2：把步骤写成代码

```python
scores = [45, 60, 88, 92, 50]
count = 0
for score in scores:
    if score >= 60:
        count = count + 1
print(count)
```

讲解：代码其实就是把算法步骤翻译成 Python。

### 示例 3：用函数封装步骤

```python
def count_pass(scores):
    count = 0
    for score in scores:
        if score >= 60:
            count = count + 1
    return count

print(count_pass([45, 60, 88, 92, 50]))
```

讲解：函数可以把一个完整的小任务打包起来，之后重复使用。
