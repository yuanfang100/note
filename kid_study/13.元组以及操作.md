# 13. 元组以及操作

元组和列表很像，都能保存多个有顺序的数据。但元组一旦创建，元素不能被修改。它适合保存固定数据，比如坐标、日期、函数返回的多个结果。

本章目标：

1. 理解元组的特点和使用场景。
2. 掌握创建、读取、遍历、切片。
3. 理解元组不可变。
4. 掌握元组拆包。
5. 理解元组和列表的区别。

---

## 1. 元组基础

元组通常使用小括号 `()` 表示。

### 示例 1：坐标

```python
point = (3, 5)
print(point)
```

讲解：坐标通常由固定数量的数据组成，适合使用元组。

### 示例 2：日期

```python
date = (2026, 6, 27)
print(date)
```

讲解：年、月、日作为整体保存。

### 示例 3：混合数据

```python
student = ("李华", 13, 88)
print(student)
```

讲解：元组也可以保存不同类型的数据。

---

## 2. 单元素元组

只有一个元素的元组，必须加逗号。

### 示例 1：错误理解

```python
value = (10)
print(type(value))
```

讲解：`(10)` 会被 Python 当成普通整数。

### 示例 2：正确单元素元组

```python
value = (10,)
print(type(value))
```

讲解：逗号才是单元素元组的关键。

### 示例 3：字符串单元素元组

```python
name_tuple = ("李华",)
print(name_tuple)
```

讲解：不管元素类型是什么，单元素元组都需要逗号。

---

## 3. 读取元组元素

元组和列表一样支持索引。

### 示例 1：读取第一个元素

```python
point = (3, 5)
print(point[0])
```

讲解：索引从 0 开始。

### 示例 2：读取最后一个元素

```python
date = (2026, 6, 27)
print(date[-1])
```

讲解：`-1` 表示最后一个元素。

### 示例 3：获取长度

```python
student = ("李华", 13, 88)
print(len(student))
```

讲解：`len()` 可以获取元组元素个数。

---

## 4. 元组不可变

元组创建后，不能修改、添加或删除其中的元素。

### 示例 1：不能修改元素

```python
point = (3, 5)
# point[0] = 10
print(point)
```

讲解：取消注释会报错，因为元组不可变。

### 示例 2：可以重新赋值变量

```python
point = (3, 5)
point = (10, 20)
print(point)
```

讲解：变量可以指向新的元组，但原来的元组本身没被修改。

### 示例 3：元组中包含列表

```python
data = ([1, 2], "scores")
data[0].append(3)
print(data)
```

讲解：元组不能换元素，但如果元素本身是可变对象，比如列表，列表内部仍可修改。

---

## 5. 遍历元组

### 示例 1：直接遍历

```python
colors = ("red", "green", "blue")
for color in colors:
    print(color)
```

讲解：元组可以像列表一样遍历。

### 示例 2：索引遍历

```python
colors = ("red", "green", "blue")
for i in range(len(colors)):
    print(i, colors[i])
```

讲解：需要索引时可以用 `range(len())`。

### 示例 3：enumerate 遍历

```python
colors = ("red", "green", "blue")
for index, color in enumerate(colors):
    print(index, color)
```

讲解：`enumerate()` 同样适用于元组。

---

## 6. 元组切片

元组支持切片，结果仍然是元组。

### 示例 1：取前两个

```python
numbers = (10, 20, 30, 40)
print(numbers[:2])
```

讲解：得到包含前两个元素的新元组。

### 示例 2：取中间部分

```python
numbers = (10, 20, 30, 40)
print(numbers[1:3])
```

讲解：包含索引 1 和 2。

### 示例 3：反向

```python
numbers = (10, 20, 30, 40)
print(numbers[::-1])
```

讲解：可以用切片得到反向元组。

---

## 7. 元组拆包

拆包可以把元组中的值一次赋给多个变量。

### 示例 1：坐标拆包

```python
point = (3, 5)
x, y = point
print(x)
print(y)
```

讲解：变量数量要和元组元素数量一致。

### 示例 2：函数返回多个值

```python
def get_min_max(numbers):
    return min(numbers), max(numbers)

smallest, largest = get_min_max([3, 8, 1, 9])
print(smallest, largest)
```

讲解：函数返回多个值时，常用元组拆包接收。

### 示例 3：交换变量

```python
a = 10
b = 20
a, b = b, a
print(a, b)
```

讲解：这其实也利用了元组打包和拆包。

---

## 8. 元组常用方法

元组方法不多，因为它不可变。

### 示例 1：count

```python
numbers = (1, 2, 2, 3, 2)
print(numbers.count(2))
```

讲解：`count()` 统计某个元素出现次数。

### 示例 2：index

```python
numbers = (10, 20, 30)
print(numbers.index(20))
```

讲解：`index()` 返回元素第一次出现的位置。

### 示例 3：in 判断

```python
subjects = ("语文", "数学", "英语")
print("数学" in subjects)
```

讲解：元组也支持成员判断。

---

## 9. 元组和列表的区别

### 示例 1：列表适合可变数据

```python
tasks = ["写作业", "读书"]
tasks.append("运动")
print(tasks)
```

讲解：任务清单经常变化，适合列表。

### 示例 2：元组适合固定数据

```python
screen_size = (1920, 1080)
print(screen_size)
```

讲解：屏幕宽高作为一组固定数据，适合元组。

### 示例 3：列表和元组转换

```python
numbers_tuple = (1, 2, 3)
numbers_list = list(numbers_tuple)
numbers_list.append(4)
print(numbers_list)
print(tuple(numbers_list))
```

讲解：可以在列表和元组之间转换。
